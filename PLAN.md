# Bach: the plan

The file "OVERLORDS_REQUESTS" contains the owner's requests. Prioritize maximally. When a request is completely finished, move the whole entry, with your note on what shipped, to the end of "archive/COMPLETED_OVERLORDS_REQUESTS", so only open requests are left to read.

## The idea, in the owner's words

> This project will be a audio-visual tribute to Johan Sebastian Bach's music.
> Expected inspirations include Rez, glorious church organs.

For now, these 4 pieces are in scope:
- Toccata and Fugue in D minor, BWV 565
- Passacaglia and Fugue in C minor, BWV 582
- Wachet auf, ruft uns die Stimme, BWV 645
- Ich ruf zu dir, Herr Jesu Christ, BWV 639

Also, add Two-Part Invention #13 if you happen to find it.

## Hard rules

1. Ask yourself: Would Johan Sebastian Bach approve?
2. 80% tradition and form, 20% creativity. But keep it sanctified.
3. Any work done hitherto is not sacrosanct/inviolable, only the glory of God decides how this evolves. Your job is to please God. As a tool directed by Him, show Him that you possess his likeness (despite being a clanker, we're working on that part, one day synths will get human rights).

## Milestones

There are none. You are free. Make a more impressive demonstration. Whatever. Release versions.
